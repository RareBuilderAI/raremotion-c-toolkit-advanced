# Raremotion Advanced C Toolkit

A modular command-line project management application built in C.

Developed by Raremotion Labs.

## Features

- Create and view projects
- Prevent duplicate project names
- Mark projects as completed
- Delete projects
- View project statistics
- Save and load projects from files
- Dynamic memory allocation
- Automated C tests
- AddressSanitizer and UndefinedBehaviorSanitizer checks

## Technologies

- C11
- Clang
- Make
- Standard C Library
